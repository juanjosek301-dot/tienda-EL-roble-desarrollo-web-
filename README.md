# 🏪 Mercado El roble 

## Descripción del proyecto

Mercado La Esquina es una página web creada para un minimercado.
La idea del proyecto es mostrar los productos que se encuentran
disponibles y permitir que los clientes puedan realizar un pedido
de una manera sencilla.

La página cuenta con una página de inicio, un catálogo de productos,
una sección con información sobre el mercado y un formulario para
realizar pedidos.

El proyecto se está desarrollando utilizando HTML, CSS y JavaScript,
sin utilizar frameworks.

---

## Páginas del proyecto

### Inicio

En esta página se presenta el mercado y se muestran algunas de sus
categorías y productos destacados.

### Catálogo

En esta sección se pueden consultar los productos del mercado y
organizarlos por diferentes categorías.

### Sobre nosotros

Esta página contiene información sobre Mercado La Esquina, los
productos que ofrece y el objetivo del negocio.

### Realizar pedido

Aquí se encuentra el formulario que permite al cliente ingresar
sus datos y la información relacionada con el pedido.

---

## Tecnologías utilizadas

Para desarrollar el proyecto se utilizan:

- HTML5
- CSS3
- JavaScript

No se utilizan frameworks, ya que el proyecto se realiza con las
tecnologías vistas durante la clase.
